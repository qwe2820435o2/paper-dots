# dottypic.com 博客使用说明

写给日常发布文章、运营博客的人看。技术架构和开发细节不在这里，需要的话
看 `docs/dottypic-blog-integration.md` 和
`docs/blog-integration-progress.md`。

## 一、这套博客是怎么运作的（简单理解就行）

- 你在 **WordPress 后台**写文章、排版、发布。
- 网站的 **`dottypic.com/blog`** 会自动把 WordPress 里发布的文章展示
  出来，长得和主站一模一样（同一个导航栏、同一个页脚、同一套配色），
  访客感觉不到这是两个系统拼起来的。
- WordPress 只是"内容仓库 + 编辑器"，访客永远不会看到、也不会跳转到
  WordPress 那个后台域名。

## 二、怎么发一篇新文章

1. 登录 WordPress 后台：

   ```
   https://wordpress-dot.up.railway.app/wp-admin/
   ```

   用你的账号密码登录。

2. 左侧菜单 **文章 → 写文章**，正常用编辑器排版：
   - 标题、正文、图片、表格、代码块、引号、列表、按钮，都可以正常用。
   - 想给文章设置封面图（会显示在博客列表页的卡片上），在右侧
     **特色图片** 里上传设置。
   - 如果想在文章里插入指向**另一篇博客文章**的链接，用编辑器的链接
     搜索功能，直接搜文章标题选中它，**不要手动去 WordPress 后台复制
     粘贴那篇文章的网址**——用搜索选中的方式，系统会自动把链接处理成
     跳转到 `dottypic.com/blog/...`；如果手动粘贴 WordPress 后台的
     网址，可能会导致读者点击后跳到错误的地方。

3. 排版完成后，点击右上角 **发布**（不是"保存草稿"）。

4. **最多等 60 秒**，去 `https://dottypic.com/blog` 刷新页面，新文章
   就会出现。不需要重新部署网站，也不需要联系开发。

## 三、发布之后，怎么确认没问题

新文章发布后，建议花一分钟自查：

- [ ] 打开 `dottypic.com/blog`，确认新文章出现在列表最上面
- [ ] 点进文章详情页，标题、正文、图片显示正常
- [ ] 如果文章里有链接到别的文章的内链，点一下，确认跳转后地址栏
      还是 `dottypic.com/blog/...`，**没有跳到** `wordpress-dot.up.railway.app`
      这种陌生地址
- [ ] 如果设置了特色图片，确认列表页卡片上的图显示的是你设置的图，
      不是默认的波点占位图案

## 四、常见问题

### 文章发布了，但 `dottypic.com/blog` 上没出现

- 先确认是不是点了"发布"而不是"保存草稿"——草稿不会显示在前台。
- 等够 60 秒再刷新，这是正常的更新延迟，不是故障。
- 如果等了几分钟还没出现，可能是 WordPress 服务器（部署在 Railway）
  临时访问不了，找开发人员看一下 Railway 上的服务状态。

### 图片显示不出来 / 显示成一个破损图标

- 检查图片是不是真的上传成功了（回 WordPress 后台看这篇文章，图片
  在编辑器里是不是能正常预览）。
- 如果编辑器里能看到图片，但前台 `dottypic.com/blog` 看不到，找开发
  人员排查（可能是图片域名白名单没更新之类的技术问题）。

### 表格 / 代码块 / 按钮这些排版元素，样式看起来很奇怪或者很丑

- 这些样式是开发那边单独写的 CSS 来适配 WordPress 的排版功能，如果
  某个元素显示效果不理想（比如颜色不对、间距太挤），把截图发给开发
  人员，让他们调整对应的样式代码，不需要你自己去改。

### 想加一个新的导航菜单项（不只是 Blog）

- 这个不是在 WordPress 后台改的，导航栏是主站代码的一部分，需要找
  开发人员帮忙加。

### 文章链接点开后显示"未找到"，但文章其实是存在的

- 先检查一下文章的网址拼写是不是有误（比如中文或特殊符号可能导致
  网址生成得不太对）。
- 如果确认文章确实发布了、链接也没打错还是显示未找到，找开发人员看
  一下，可能是缓存没刷新或者其他技术问题。

## 五、暂时还做不到 / 需要注意的地方

- **多语言**：目前博客文章只有英文，`dottypic.com/blog`、
  `dottypic.com/jp/blog`、`dottypic.com/id/blog` 三个语言的入口虽然都
  存在，但内容目前都是同一份英文文章（还没有做真正的多语言博客内容）。
  以后如果要支持日语/印尼语单独的博客文章，需要额外开发，不是现在
  这套系统能直接做到的。
- **WordPress 后台账号安全**：请**不要把 WordPress 后台账号分享给
  不信任的人**。因为文章正文目前是直接展示的，没有做额外的安全过滤，
  如果后台账号被盗用，有被用来攻击网站的风险。只给需要发文章的人开
  账号，密码要妥善保管。
- **删除文章要谨慎**：如果一篇文章被别的文章通过内链链接过，删除后
  那个内链会失效（变成"未找到"），发布前如果不确定，建议先"移到
  回收站"观察一段时间，而不是直接永久删除。

## 六、需要联系开发人员的情况

以下情况自己在 WordPress 后台是处理不了的，需要找开发：

- 想加新的导航菜单项、调整博客整体版式或配色
- 想支持多语言博客文章
- 文章列表分页数量想调整（目前固定每页 9 篇）
- 网站长时间无法访问、大面积样式错乱
- 想给博客加评论功能、分类筛选、搜索等目前没有的新功能
